# FLASHY ADMIN PANEL

Android demo app with a black-and-red interface.

## Features
- Execute generates a random integer from 0 to 9.
- Displays demo Big/Small and colour labels.
- No history section.

**Important:** Random demonstration only. It is not connected to RAXI Win and cannot predict or control game outcomes.

## Build
GitHub Actions builds a debug APK on every push to main or by manual dispatch. Open the Actions tab and download the `FLASHY-ADMIN-PANEL-debug-apk` artifact after a successful run.
